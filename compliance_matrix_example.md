# Ejemplo de matriz de cumplimiento

Este archivo ilustra cómo podría estructurarse una matriz de cumplimiento
utilizando el Juridico Compliance Framework.

- Norma: Ley General de Responsabilidades Administrativas
- Artículo: 7
- Obligación: Integrar mecanismos de control interno
- Responsable: Órgano interno de control
- Evidencia: Manual de organización y procedimientos
